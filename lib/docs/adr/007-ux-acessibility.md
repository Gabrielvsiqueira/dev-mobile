# 007 - UX para Acessibilidade

## Status
Aceito

## Contexto
O público-alvo são idosos com baixa familiaridade tecnológica.

## Decisão
Aplicar diretrizes de acessibilidade na UI:
- Fonte maior
- Botões grandes
- Poucas ações por tela
- Feedback visual
- Wizard passo a passo

## Consequências
✅ Melhor usabilidade  
✅ Redução de erros  
❌ Interface menos densa (menos informação por tela)
